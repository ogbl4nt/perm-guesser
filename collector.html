Сборщик точек

Берёт границу Перми из OpenStreetMap (один запрос) и сам ищет панорамы Яндекса по всем районам внутри неё. На выходе файл points.json с проверенными точками. Открывайте эту страницу только по адресу GitHub Pages, не с диска. Вкладку не закрывайте, можно нажать «Стоп» в любой момент: то, что уже найдено, скачается.
